    About SecureVault

    Version 1.0.0 · Container format v1

    How it works

    SecureVault generates a random 256-bit key using your browser's cryptographically secure random number generator, then encrypts your data with AES-256-GCM through the native Web Crypto API. Large files and folders are split into independently-authenticated chunks so nothing needs to fit entirely in memory and the page stays responsive. Every chunk is bound to the file's header, so tampering with the filename, reordering chunks, or truncating the file is detected automatically.

    Your privacy

    • No servers, no accounts, no network requests of any kind
    • No analytics or telemetry
    • Keys live only in this tab's memory — never written to disk or storage
    • Only non-sensitive settings (like theme) are ever saved, and only on your device
